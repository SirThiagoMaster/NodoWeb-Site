# Sobre este proyecto

Sitio web de Nodo Web — mi negocio de automatización y desarrollo web
(WhatsApp, sitios, herramientas internas para pequeños negocios en Medellín).

Este es el sitio de la propia marca Nodo Web, no el de un cliente.
Incluye un mapa de cobertura (Leaflet) mostrando la zona de servicio en Medellín.

## Stack observado
- HTML/CSS/JS plano (sin framework por ahora)
- Leaflet para mapas
- Sin backend todavía
